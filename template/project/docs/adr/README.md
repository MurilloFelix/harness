# Architecture Decision Records

Um ADR registra **uma** decisão: o contexto, o que foi decidido e o que isso custa. Serve para o você do futuro (e a IA) não desfazer uma decisão sem saber por que ela foi tomada.

- Numeração sequencial, nunca reaproveitada.
- Um ADR aceito não é editado. Se a decisão mudar, escreva um novo e marque o antigo como `Substituído por NNNN`.
- Use [`0000-template.md`](0000-template.md).
